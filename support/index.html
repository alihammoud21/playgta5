Black world, working audio or map

Close the game tab and try the lower-memory link above. Compare Story and Sandbox modes. If the world stays black, open browser developer tools (F12 on Windows; ⌥⌘I on Mac), capture the first WebGPU / shader errors, and attach them with these diagnostics to issue #2. A working menu does not prove that world shaders or all game files loaded.

Graphics device lost or loading stuck

Close every game tab, stop this server with Ctrl+C, and launch again. Update the browser and graphics driver (macOS updates supply Mac drivers). Check chrome://gpu or edge://gpu for hardware acceleration and Problems Detected. Close GPU-heavy apps. Post the first error and diagnostics to issue #1.

If files fail to load, run Verify-Game.cmd (Windows) or Verify-Game.command (Mac). This page makes no changes to saves or browser storage. Review copied diagnostics before posting; they include browser and GPU information.
