01 / Windows

Download. Launch. Play.

  1. Extract the installer ZIP completely.
  2. Run Download-Game.cmd. Keep the window open until installation finishes.
  3. Run Launch-Local.cmd. Keep its server window open.
  4. Open the local compatibility page in Chrome or Edge and start with the lower-memory option.

02 / Mac · Experimental gameplay

A native launch path.

  1. Install Python 3.11 or newer and extract the installer ZIP.
  2. Open Terminal in the extracted folder, then run:
bash Download-Game.command
bash Launch-Local.command

Use current Chrome or Edge. Apple Silicon and Intel use the system Python; the Windows runtime is skipped. Mac gameplay still needs hardware testing.

03 / Troubleshooting

Sound and map, but a black world?

After starting the local server, try lower-memory mode at 720p / 30 FPS. Close other game tabs and GPU-heavy apps. Verify the game files, then collect browser-console errors if it persists.

In the updated installer, the local compatibility page produces a report you can review and share. Local links work only while your server is running.

Already installed?

Keep your existing game files. Download the latest installer ZIP and copy its helper files and support folder into your existing installation, replacing the older helpers. Then run the launcher. Do not re-extract the old release helpers over the update.
